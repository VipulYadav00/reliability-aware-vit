# Reliability-Aware Vision Transformer

MSc Computer Science final-year research project.

## Goal
Investigate reliable medical-image classification under distribution shift using a task-specific Vision Transformer (ViT), calibration, uncertainty estimation, OOD detection, and selective prediction.

## Workflow
- Develop locally in VS Code; use Google Colab T4 for GPU-heavy training.
- Use GitHub for source code and suitable cloud storage for datasets/checkpoints.
- Do not commit datasets, checkpoints, credentials, or private data to GitHub.

## Status
Scaffold only. Confirm dataset, labels, research gap, and experimental protocol before full implementation.

## Setup
1. Create environment from `environment.yml`.
2. Activate it and run `python scripts/check_environment.py`.
3. Read `data/README.md`.
4. Start with the dataset audit notebook.
